Condicionales en JavaScript

Esta actividad muestra cómo funcionan los condicionales if, else if y else.

Resultado de la actividad

Los mensajes de console.log() se pueden ver en la consola del navegador.

Presiona F12 y entra en la pestaña Console para ver los resultados.

Primer condicional

if (false) {
    console.log("Este mensaje no se mostrará");
} else if (false) {
    console.log("Este mensaje tampoco");
} else if (false) {
    console.log("Este mensaje SI se mostrará 👋😁");
} else {
    console.log("A mi no me verás 😑🙄");
}

¿Por qué sale ese resultado?

Todas las condiciones anteriores son false.

Como ningún if ni else if se cumple, JavaScript llega al else y ejecuta su mensaje.

Segundo condicional

if (true) {
    console.log("Este mensaje no se mostrará");
} else if (true) {
    console.log("Este mensaje tampoco");
} else if (true) {
    console.log("Este mensaje SI se mostrará 👋😁");
} else {
    console.log("A mi no me verás 😑🙄");
}

¿Por qué sale ese resultado?

La primera condición es true.

Por eso JavaScript ejecuta inmediatamente el código dentro del primer if. Los else if y el else ya no se revisan.

Tercer condicional

if (false) {
    console.log("Este mensaje no se mostrará");
} else if (true) {
    console.log("Este mensaje tampoco");
} else if (true) {
    console.log("Este mensaje SI se mostrará 👋😁");
} else {
    console.log("A mi no me verás 😑🙄");
}

¿Por qué sale ese resultado?

El primer if es false, por lo tanto no se ejecuta.

Después se revisa el primer else if, que es true. Por eso se ejecuta ese mensaje y JavaScript deja de revisar las demás condiciones.
